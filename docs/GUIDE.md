# VOICEROID POCKET 使い方ガイド

琴葉茜・琴葉葵などのキャラクターが、アプリの画面・ホーム画面のウィジェット・通知で話しかけてくれるアプリです。このガイドでは、アプリの使い方を順番に説明します。

## 1. はじめに

- Android 13 以上のスマホで使えます。
- 初めて開いたときに通知の許可を聞かれます。朝や深夜にキャラから通知を受け取りたいときは「許可」を選んでください。
- 最初から琴葉茜・琴葉葵の2人が入っています。

## 2. ホーム画面

- **キャラをタップ**すると、セリフが変わります(直前と同じセリフは避けます)。
- 何もしなくても**1分ごと**に次のセリフに変わります。半分の確率で、今の時間帯や曜日に合ったセリフを選びます。
- 3日以上ぶりに開くと、「久しぶり」のセリフで迎えてくれます。
- 上に並んだ**サムネイル**で、話すキャラを切り替えます。
- 「**キャラを追加**」で新しいキャラを作れます。
- 「**編集する**」で、今表示しているキャラを編集します。
- 「**ボイス オン/オフ**」で、セリフが変わったときにボイスを自動で鳴らすかを切り替えます。
- 吹き出しの**スピーカーボタン**で、今のセリフのボイスをもう一度聞けます(ボイスがオフでも鳴ります)。
- 茜・葵を削除したときは、「琴葉 茜を呼び戻す」のようなボタンが出るので、それで戻せます。

> 「通知を試す」は動作確認用のボタンです。押すと、今選んでいるキャラからすぐに通知が1つ届きます。

## 3. ウィジェットを置く

1. ホーム画面の何もないところを長押しして、「ウィジェット」を開きます。
2. このアプリの「キャラクター」ウィジェットを選んで置きます。
3. 表示するキャラを選びます。

- ウィジェットを**タップ**するとセリフが変わり、ボイスがあれば鳴ります。
- **30分ごと**に、今の状況に合ったセリフに変わります。
- 表示するキャラは、ウィジェットを長押しして「設定」から選び直せます。
- アプリでキャラを編集して保存すると、置いてあるウィジェットにもすぐ反映されます。
- ウィジェットの文字は、スマホの標準のフォントで表示されます。

## 4. 通知

- **朝7〜9時台**に起こしてくれる通知、**深夜0〜3時台**に「早く寝て」と怒る通知が、それぞれ1日1回届きます。
- どのキャラが話しかけてくるかはランダムです。

## 5. キャラを追加・編集する

ホーム画面の「キャラを追加」か「編集する」で、編集画面が開きます。最後に右上の「**保存する**」を押すと確定します。保存せずに「キャンセル」で戻ろうとすると、確認が出ます。

### プロフィール

| 項目 | 内容 |
| --- | --- |
| 名前 | キャラの名前。ウィジェットや吹き出しの名札に出ます |
| テーマ色 | 10色から選びます。最後の「＋」を押すと、自分で色を決められます(下を参照) |
| 動き方 | 待っている間の動きを選びます。横のお試し表示で動きを確かめられます |

**テーマ色を自分で決める**
- 「＋」を押すと「テーマ色を決める」画面が開きます。
- 「色相」「鮮やかさ」「明るさ」のスライダーで色を作るか、「カラーコード」に `#FFB3BE` のように入力します(全角で入力しても大丈夫です)。
- 上の見本で、名札と文字の見え方を確かめながら選べます。「決定」で決まります。
- 淡い色がおすすめです。濃い色にすると、上に乗る文字が白になります。

**動き方**

| 動き方 | 動き |
| --- | --- |
| 動かない | じっと待っています |
| ふわふわ | ゆっくり上下に揺れます |
| ゆらゆら | 足元を軸に、左右にゆっくり傾きます |
| ぴょこぴょこ | ときどき小さく2回跳ねます |
| すーはー | 息をするように、少しだけふくらみます |

> スマホの設定で「アニメーションを削除」(動きを減らす)をオンにしていると、どの動き方でも動きません。

### 表情

- 「表情を追加」で、スマホの画像を選び、表情の名前を付けて追加します。
- 表情をタップすると、画像の差し替え・名前の変更・削除ができます。
- 先頭の表情が「**基本の表情**」です。「基本の表情にする」で入れ替えられます。
- 表情を削除すると、その表情を使っていたセリフは基本の表情になります。

### セリフ

- 「＋ セリフを追加する」で、セリフを書きます。セリフをタップすると編集できます。
- セリフごとに、**文章・表情・いつ話すか・ボイス**を決めます。
- 一覧は、いつ話すかの種類ごとに絞り込んで表示できます。

**いつ話す？**(1つのセリフに1つ選びます)

| 種類 | 話すとき |
| --- | --- |
| いつでも | 普段のセリフ。タップしたときなどに話します |
| 時間帯 | 朝(5〜9時)・昼(10〜16時)・夕方(17〜21時)・夜(22〜23時)・深夜(0〜4時) |
| 曜日 | 選んだ曜日(いくつでも選べます。「平日にする」「週末にする」でまとめて選べます) |
| 記念日 | 毎年その日(月・日と、記念日の名前) |
| 充電中 | 充電しているとき |
| 電池が少ない | 充電していなくて、残りが15%以下のとき |
| 久しぶり | 3日以上ぶりにアプリを開いたとき(最初の1回だけ) |

- 「久しぶり」→「記念日」の順に優先します。それ以外は、今当てはまるセリフの中から選びます。当てはまるセリフがなければ、普段のセリフを話します。
- 充電や電池のセリフは、充電器を差した瞬間ではなく、次にセリフが変わるときに話します。

### その他

- 「このキャラを削除する」で、キャラを削除します。
- 茜・葵は「初期状態に戻す」で、最初の内容に戻せます(追加・編集した表情やセリフはすべて消えます)。

## 6. ボイスを付ける

セリフごとに、ボイス(音声ファイル)を付けられます。

- **1つずつ付ける**:セリフの編集画面で「ボイスを選ぶ」から音声ファイルを選びます。「聞く」で確かめ、「外す」で外せます。
- **まとめて付ける**:トークソフトで作ったボイスを、フォルダごと読み込めます(次の章)。
- 鳴らせる形式は WAVE(.wav)・MP3 などです。WMA と、ヘッダーなしの RAW は鳴らせません。

## 7. トークソフトでボイスをまとめて作る

アプリからセリフのリスト(テキストファイル)を書き出して、パソコンのトークソフトでボイスを作り、できたボイスをまとめて読み込めます。

対応しているソフト:**A.I.VOICE・A.I.VOICE2・VOICEROID2・VOICEVOX・VOICEPEAK・VoiSona Talk**

### 全体の流れ

1. 編集画面の「ボイス」で「**トークソフト用のリストを書き出す**」を押します。
2. 「使うソフト」と「書き出すセリフ」(ボイスがないセリフだけ/すべて)を選んで、「書き出す」を押します。保存する場所を選ぶと、`琴葉 葵_VOICEVOX.txt` のようなファイルができます。
3. ファイルをパソコンに移して、トークソフトでボイスを作ります(手順は下のソフトごとの説明か、書き出したあとアプリに出る「作り方」を見てください)。
   - ポイントは「**1セリフ = 1音声ファイル**」で書き出すことと、「**テキストファイルも一緒に保存する**」ことです。
4. できたフォルダをスマホにコピーして、「**ボイスのフォルダを読み込む**」で選びます。ファイルを個別に選ぶときは「ファイルを選んで読み込む」を使います。
5. セリフにボイスが付いたら、右上の「**保存する**」を押して確定します。

> 一緒に保存されたテキストファイルの中身でセリフを探すので、音声ファイルの名前は自由に変えても大丈夫です。テキストファイルがないときは、ファイル名の連番と、書き出したときの順番で対応づけます。

### 話者(声)の指定

| ソフト | テキストでの指定 |
| --- | --- |
| A.I.VOICE・VOICEROID2 | 「ボイスプリセットを指定する」をオンにすると、各セリフの先頭に `琴葉 葵＞` のようなタグを付けます。プロンプト文字列(`＞`)は、ソフトの「プロジェクト設定」→「ボイス」と同じにしてください |
| VOICEVOX | 「キャラクターを指定する」をオンにすると、行の先頭に `ずんだもん（ノーマル）,` のようにキャラ名を付けます。VOICEVOX のキャラ名と同じにしてください(最初はアプリのキャラ名が入っているので書き換えます)。スタイルは全角のかっこで付けます |
| A.I.VOICE2・VOICEPEAK・VoiSona Talk | テキストでは指定できません。ソフトの画面でキャラを選んでください |

### ソフトごとの手順

#### A.I.VOICE / VOICEROID2
1. エディターの「ファイル」→「テキストを開く」で、書き出したファイルを開きます。
2. 「音声保存」で次のように設定して保存します。
   - ファイル分割:「指定された文字列で区切って複数のファイルに書き出す」、区切り文字列は `##`
   - ファイル形式:WAVE(ファイルヘッダーあり)か MP3
   - 「テキストファイルを音声ファイルと一緒に保存する」にチェック
   - ファイル命名規則:`{Number}`(連番の開始番号は1)

> 「1文ごとに区切って複数のファイルに書き出す」は使わないでください。「何か用ですか？…呼んでみただけ、ですか。」のような2文以上のセリフが、別々のファイルに分かれてしまいます。

#### A.I.VOICE2
1. 書き出したファイルをメモ帳などで開いて、全部コピーします。
2. テキストブロックに貼り付けて、「改行位置で分割」で1行ずつのブロックに分けます。
3. 「アプリケーション設定」の書き出しで、「テキストファイルを音声ファイルと一緒に保存する」にチェックを入れ、ファイル命名規則に「テキストブロック番号」を入れます。
4. 「一括書き出し (すべて)」で、「テキストブロックごとにファイルに書き出す」を選んで書き出します。

#### VOICEVOX
1. 「ファイル」→「テキスト読み込み」で、書き出したファイルを読み込みます(1行が1つのテキスト欄になります)。
2. 「設定」→「オプション」の「保存」で、「txtファイルを書き出し」をオンにします。文字コードは UTF-8 にします。
3. 「ファイル」→「音声書き出し」で、全部のテキスト欄を WAV で書き出します。

#### VOICEPEAK
1. 「テキストファイルを開く」で、分割文字に「改行」を指定して開きます(1行が1ブロックになります)。
2. 出力設定で次のように設定して書き出します。
   - 「ブロックごとに分割して保存」をオン(命名規則の先頭は連番にする)
   - 「セリフをファイルに保存」をオン
   - 形式は WAV か FLAC

> VOICEPEAK は1ブロック140文字までです。超えるセリフがあると、書き出す画面に数が出ます。

#### VoiSona Talk
1. 書き出したファイルをメモ帳などで開いて、全部コピーします。
2. 文のリストに貼り付けます(1行が1つの文になります)。
3. 書き出しで「文ごと」のファイル書き出しを選び、WAV と Text にチェックを入れて書き出します。

> VoiSona Talk は1文500文字までです。

### リストを書き出すときに自動でしていること

- 1行1セリフのソフト(A.I.VOICE・VOICEROID2 以外)では、セリフの中の改行をつなげて1行にします。
- 区切りとして扱われてしまう文字は、全角にします(A.I.VOICE・VOICEROID2 の `##`、VOICEVOX の半角コンマ、VoiSona Talk の半角 `<`)。
- 読み込むときは、全角と半角、空白、改行、先頭の話者の指定の違いを気にせずに、セリフと照らし合わせます。

## 8. 困ったとき

**ボイスが鳴らない**
- ホーム画面の「ボイス オン/オフ」がオフになっていないか確かめてください(オフでも、スピーカーボタンでは鳴ります)。
- WMA や、ヘッダーなしの RAW は鳴らせません。WAVE(ファイルヘッダーあり)か MP3 で保存し直してください。

**ボイスを読み込んでも、セリフに付かない**
- 音声と同じ名前のテキストファイル(.txt)も一緒にスマホにコピーしたか確かめてください。
- 書き出したあとにセリフの文章を書き換えると、テキストの中身が合わなくなります。もう一度リストを書き出して作り直してください。
- 読み込みのあとに出る「ボイスを読み込みました」の画面の「合うセリフが見つからなかったファイル」に、対応づけられなかったファイルが出ます。

**キャラが動かない**
- 動き方が「動かない」になっていないか確かめてください。
- スマホの「アニメーションを削除」(動きを減らす)がオンだと動きません。

**通知が来ない**
- スマホの設定で、このアプリの通知が許可されているか確かめてください。

**茜・葵を消してしまった**
- ホーム画面に出る「(キャラ名)を呼び戻す」ボタンで戻せます。
