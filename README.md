# WidgetVoiceroid(VOICEROID POCKET)

琴葉茜・琴葉葵をはじめとするキャラクターが、ホーム画面のウィジェット・アプリ画面・通知で話しかけてくれる Android アプリです。キャラクターや表情、セリフはアプリ上から自由に追加・編集できます。

アプリの使い方は [使い方ガイド](docs/GUIDE.md) にまとめています。

## できること

### キャラと話す(ホーム画面)
- キャラをタップすると、普段のセリフからランダムに話してくれます(直前と同じセリフは避けます)。
- 1分ごとに自動で次のセリフに切り替わります。半分の確率で、今の状況(時間帯・曜日など)に合ったセリフを選びます。
- 3日以上ぶりにアプリを開くと、「久しぶり」のセリフで迎えてくれます。
- 上のサムネイルでキャラを切り替えられます。切り替えると、右からスライドしながらフェードインします。
- キャラは待っている間に動きます。動き方は「動かない・ふわふわ・ゆらゆら・ぴょこぴょこ・すーはー」からキャラごとに選べます(端末の「動きを減らす」設定がオンなら動きません)。

### ホーム画面ウィジェット
- ウィジェットは「キャラクター」の1種類です。置くときに、表示するキャラを選びます。長押しの「設定」から選び直すこともできます。
- タップするとセリフが変わります。
- 30分ごとに、今の状況に合ったセリフに切り替わります。
- アプリでキャラを編集して保存すると、置いてあるウィジェットにもすぐ反映されます。

### 通知
- 朝7〜9時台には起こしてくれる通知、深夜0〜3時台には「早く寝て」と怒る通知が、それぞれ1日1回届きます。
- 話しかけてくるキャラはランダムです。アイコンには、立ち絵から顔の部分を切り抜いて使います。

### キャラの追加・編集
| 項目 | 内容 |
| --- | --- |
| プロフィール | 名前、テーマ色(淡い10色から選ぶか、「＋」で色相・鮮やかさ・明るさのスライダーやカラーコード(#RRGGBB)で自分で決める)、動き方(お試し表示つき) |
| 表情 | 端末の画像を選んで、名前を付けて追加。画像の差し替え・名前の変更・削除ができる。先頭が「基本の表情」 |
| セリフ | 文章・表情・いつ話すか(下の「話す状況」)・ボイスを設定。種類ごとに絞り込んで一覧できる |
| ボイス | トークソフト(A.I.VOICE・A.I.VOICE2・VOICEROID2・VOICEVOX・VOICEPEAK・VoiSona Talk)用のセリフリストの書き出しと、作ったボイスのまとめての読み込み(下の「ボイス」) |
| その他 | キャラの削除。茜・葵は「初期状態に戻す」もできる |

- 保存せずに戻ろうとすると確認が出ます。画面を回転しても編集中の内容は消えません。
- 茜・葵を削除しても、ホーム画面の「茜・葵を呼び戻す」ボタンで戻せます。

### 話す状況
セリフごとに「いつ話すか」を1つ選べます。

| 種類 | 話すとき |
| --- | --- |
| いつでも | 普段のセリフ。タップしたときなどに話す |
| 時間帯 | 朝(5〜9時)・昼(10〜16時)・夕方(17〜21時)・夜(22〜23時)・深夜(0〜4時) |
| 曜日 | 選んだ曜日(いくつでも選べる。「平日」「週末」もワンタッチ) |
| 記念日 | 毎年その日(月・日と、記念日の名前) |
| 充電中 | 充電しているとき |
| 電池が少ない | 充電していなくて、残り15%以下のとき |
| 久しぶり | 3日以上ぶりにアプリを開いたとき(最初の1回だけ) |

- 選び方:「久しぶり」→「記念日」の順に優先します。それ以外は、今当てはまる条件(時間帯・曜日・充電中・電池が少ない)のセリフをまとめた中から選びます。当てはまるセリフがなければ、普段のセリフから話します。
- 充電や電池は、差した瞬間ではなく、次に話すタイミング(30分ごとの更新・アプリの自動切り替え・通知)で反応します。
- 茜・葵には、曜日・お正月・クリスマス・充電・電池・久しぶりのセリフ例が入っています。

### ボイス
- セリフごとにボイス(音声ファイル)を付けられます。キャラをタップしてセリフが変わると鳴り、吹き出しのスピーカーボタンでもう一度聞けます。ウィジェットをタップしたときも鳴ります。
- ホーム画面の「ボイス オン/オフ」で、自動で鳴らすかどうかを切り替えられます(スピーカーボタンや編集画面の「聞く」はオフでも鳴ります)。
- 再生できる形式は WAVE・MP3 など(WMA や、ヘッダーなしの RAW は再生できません)。

#### トークソフトで一括で作る
1. 編集画面の「VOICE」→「トークソフト用のリストを書き出す」で、使うソフトを選んでテキストファイルを書き出す(ボイスがないセリフだけ/すべて を選べる)。
2. パソコンのソフトで取り込み、「1セリフ=1音声ファイル」で、テキストファイルも一緒に書き出す(手順は書き出したあとにアプリに出ます)。
3. できたフォルダをスマホにコピーし、「ボイスのフォルダを読み込む」で選ぶ(ファイルを個別に選んでもよい)。
4. セリフにボイスが付いたら「保存する」で確定する。

| ソフト | リストの形 | 取り込み方 | 話者の指定 |
| --- | --- | --- | --- |
| A.I.VOICE | `##` で区切る(UTF-8・BOM付き) | 「テキストを開く」→「音声保存」で「指定された文字列で区切って複数のファイルに書き出す」 | 各セリフの先頭に `琴葉 葵＞` のタグ |
| VOICEROID2 | 同上 | 同上 | 同上 |
| A.I.VOICE2 | 1行1セリフ(BOM付き) | 全部コピーしてテキストブロックに貼り付け、「改行位置で分割」→「一括書き出し」 | できない(画面で選ぶ) |
| VOICEVOX | 1行1セリフ(BOMなし) | 「テキスト読み込み」→「音声書き出し」(「txtファイルを書き出し」をオン) | 行頭に `ずんだもん（ノーマル）,` |
| VOICEPEAK | 1行1セリフ(BOMなし) | 「テキストファイルを開く」で分割文字に改行 →「ブロックごとに分割して保存」 | できない(画面で選ぶ) |
| VoiSona Talk | 1行1セリフ(BOM付き) | 全部コピーして文のリストに貼り付け → 文ごとに WAV と Text を書き出す | できない(画面で選ぶ) |

- 改行は CRLF です。1行1セリフのソフトでは、セリフの中の改行はつなげます。
- 区切りに使われる文字は全角にします(A.I.VOICE・VOICEROID2 の `##`、VOICEVOX の半角コンマ、VoiSona の半角 `<`)。
- VOICEPEAK は1セリフ140文字、VoiSona Talk は500文字までです。超えるセリフがあると書き出す画面に出ます。
- 対応づけは、一緒に保存されたテキストファイル(.txt)の中身とセリフを比べて行います(全角・半角、空白・改行、先頭の話者の指定、見出しの違いは無視)。テキストファイルがない音声は、ファイル名の連番(先頭が数字ならその数字、なければ最後の数字。0 始まりにも対応)と、書き出したときの順番で対応づけます。
- A.I.VOICE・VOICEROID2 で「1文ごとに区切って複数のファイルに書き出す」を使うと、「何か用ですか？…呼んでみただけ、ですか。」のような複数の文のセリフが別々のファイルに分かれてしまうので、区切り文字で分ける方法を使います。
- テキストファイルの文字コードは、BOM → UTF-8 → Shift-JIS の順に自動で判定します。

## デザイン

デザインシステム「VOICEROID POCKET」に沿っています。

- **色**:白い地に、茜のピンク(`#FFB3BE`)と葵の水色(`#B3E4FF`)を面で置き、文字・フチ・影はすべて紺(`#3D3A55`)。
- **形**:フチは太めの実線、影はぼかさずに右下へずらす。ステッカーを貼ったような見た目。
- **文字**:日本語は Zen Maru Gothic、英字は Fredoka(どちらもアプリに同梱)。
- **モチーフ**:キャラの後ろに斜め2色の帯、水玉、キラキラ(4点星)。
- 端末で「アニメーションを削除」をオンにしていると、動きはすべて止まります。
- 端末がダークモードでも白い地で表示します(デザインシステムがライトテーマのみのため)。
- ウィジェットでは自前のフォントが使えないため、文字は端末の標準フォントになります。

## 動作環境・ビルド

- Android 13 以上(minSdk 33、targetSdk 37)
- Kotlin + Jetpack Compose(Material3)、Glance(ウィジェット)、WorkManager(定期実行)、kotlinx.serialization(データ保存)

```sh
./gradlew assembleDebug        # APK を作る(app/build/outputs/apk/debug/app-debug.apk)
./gradlew testDebugUnitTest    # ユニットテストを実行する
```

## しくみ

### データの保存
- キャラのデータは、アプリ内の `characters.json` に保存します。
- 初めて起動したときは、`Akane.kt` / `Aoi.kt` の内容から茜・葵を作ります(この2ファイルは「初期データ」です)。
- 追加した画像はアプリ内の `images/`、ボイスは `voices/` フォルダにコピーします。どのキャラからも使われなくなったファイルは、保存のたびに自動で消えます。
- `characters.json` が壊れて読めないときは、上書きせずに別名で退避し、初期状態で起動します。
- 古い形式のデータ(時間帯だけ選べた頃のセリフ)は、読み込むときに自動で新しい形に直します。
- 内蔵キャラの初期データにセリフが増えたときは、保存済みの茜・葵に一度だけ足します(`seedRevision` で管理。編集内容はそのまま)。

### データの形
```
Character(キャラ)
├─ id, name, color(テーマ色), idleMotion(動き方。古いデータは floating から決める)
├─ aiVoice: AiVoiceSettings(トークソフト用リストの設定:ソフト・話者名・プロンプト文字列・書き出した順番)
├─ faces: List<Face>(表情。先頭が基本の表情)
│    └─ id, label(表情の名前), image(内蔵画像 or 追加した画像)
└─ lines: List<Line>(セリフ)
     └─ id, text, faceId(使う表情), condition(話す状況。null ならいつでも), voice(ボイスのファイル名)
```

### ファイル構成(`app/src/main/java/com/example/widgetvoiceroid/`)
| ファイル | 役割 |
| --- | --- |
| `Character.kt` | キャラ・表情・セリフのデータの形と、セリフを選ぶ処理 |
| `Situation.kt` | 時間帯・曜日・話す条件(`Condition`)・今の状況(`Situation`)・アプリを開いた日時の記録 |
| `BuiltInCharacters.kt` | 内蔵キャラ(茜・葵)の初期データの定義と、内蔵画像の表 |
| `Akane.kt` / `Aoi.kt` | 茜・葵の初期データ(名前・色・表情・セリフ) |
| `CharacterRepository.kt` | `characters.json` の読み書き。アプリ・ウィジェット・通知で共通 |
| `ImageStore.kt` | 画像の取り込み・縮小読み込み・不要な画像の削除 |
| `MainActivity.kt` | ホーム画面 |
| `CharacterEditor.kt` | キャラの編集画面 |
| `ColorPicker.kt` | テーマ色を自分で決めるダイアログと、カラーコードの変換 |
| `CharacterWidget.kt` | ホーム画面ウィジェット |
| `WidgetConfigActivity.kt` | ウィジェットを置くときのキャラ選択画面 |
| `SpeakWorker.kt` | 30分ごとの定期実行(ウィジェットの更新と通知) |
| `CharacterNotifier.kt` | 通知を出す |
| `CharacterImage.kt` | 表情の画像を表示する部品 |
| `Voice.kt` | ボイスの保存・再生と、ボイスのオン/オフ設定 |
| `AiVoice.kt` | トークソフトごとのリストの書き出し・作り方と、書き出したボイスの読み込み・対応づけ |
| `Motion.kt` | 待機中の動き方(ふわふわ・ゆらゆら・ぴょこぴょこ・すーはー) |
| `VpComponents.kt` | デザインシステムの部品(ボタン、吹き出し、サムネイル、見出し、斜めの帯など) |
| `ui/theme/` | 色・文字・テーマ |

## 画像について

内蔵キャラ(琴葉茜・琴葉葵)の立ち絵と、アプリのアイコン画像はリポジトリに含めていません。ビルドするときは、次の場所に自分で用意した画像を置いてください。

| 置く場所 | 内容 |
| --- | --- |
| `app/src/main/res/drawable-nodpi/akane_*.png`, `aoi_*.png` | 立ち絵(表情ごと)。必要なファイル名は `Akane.kt`・`Aoi.kt` の `R.drawable.*` を参照 |
| `app/src/main/res/mipmap-*/ic_launcher.webp`, `ic_launcher_round.webp`, `ic_launcher_foreground.webp` | アプリのアイコン(Android Studio の Image Asset で作れます) |
